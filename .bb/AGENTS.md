# Repository Instructions

Before planning or changing code, read and follow `../AGENTS.md`.

The root `AGENTS.md` contains this repository’s authoritative development, testing, architecture, and Git conventions. Those instructions supplement the global BB instructions.

## Pull requests and review

- Open or modify a pull request only when explicitly requested.
- Read the linked issue, complete branch diff, commit history, verification results, and repository pull request template before creating a PR.
- Open agent-created pull requests as drafts unless explicitly directed otherwise.
- Fill out the complete PR template; if a section does not apply, remove it, but only if absolutely confident it is not relevant.
- Do not add AI attribution, generated-by notices, or session links.
- An automated reviewer may post a comment review when explicitly authorized, but must not approve, merge, or represent itself as the human reviewer.
- Do not merge pull requests. Final approval and merge belong to a human unless the user explicitly authorizes a different policy.
- After new commits are pushed, treat previous reviews as potentially stale.
